# Design direction

## Surface
Operate: a grants steward inspects a ruling and verifies which wallets can vote.

## Direction contract
Build a compact committee dossier: warm paper surfaces, ink-dark type, restrained evergreen for confirmed states, and rust for holds or conflicts. Use a serif display voice for editorial authority and a neutral sans for controls and body copy. Dense data uses tabular numerals. The page should feel like a review record with clear before/after columns, not a generic crypto dashboard.

The first viewport opens on the fictional round and featured A/B ruling. Put the frozen clause, disclosure passage, and roster change beside each other. Keep explorer and receipt evidence legible as separate records. On mobile, stack the ruling evidence before the roster; keep wallet actions in a visible, reachable section.

## Product truth
Use fictional names and public demo disclosures. Never imply official grants policy, real identity verification, or a live transaction where none exists. Show wallet submission, consensus pending, finalized ruling, and execution failure as distinct states.
